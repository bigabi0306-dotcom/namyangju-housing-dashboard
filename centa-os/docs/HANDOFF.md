## 내일 시작 순서 (권장)

3. **`windows\backup.bat` 으로 백업해 보고**, 백업 폴더를 외장하드·클라우드에 복사.
4. 기존 사이트(010-8848-7727.com) 관리자 화면에서 **매물 CSV(또는 엑셀→CSV)** 를 받아 `매물장 → 가져오기`로 **미리보기 먼저** → 이상 없으면 실행. 고객 엑셀도 `고객관리 → 가져오기`.
5. 며칠 써 보며 불편한 점·빠진 기능을 메모 → 우선순위를 정해 다음 개발.
