# CENTA REALTY OS 사용 매뉴얼 (대표·직원용)

## 하루 업무 흐름
1. **접속 → AI 업무 브리핑**: 오늘 일정, 연락할 고객, 신규·가격 변경 매물, 확인 필요 업무가 모입니다. 항목의 **완료**·**내일로** 버튼으로 바로 처리합니다. (브리핑은 시스템에 입력된 데이터만 계산합니다. 외부 AI를 쓰지 않습니다.)
2. 상담·현장 후 **업무일지**를 씁니다. 후속조치를 적으면 후속업무(와 원하면 일정)가 자동으로 생기고, 고객 상담이력에도 연결됩니다. 유형이 "현장답사"이면 현장방문 기록과 매물 상태("현장안내")도 반영됩니다.
3. 계약이 진행되면 **계약관리**에서 상태를 올립니다. 매물·고객 단계가 함께 바뀝니다.

## 메뉴별 요약
| 메뉴 | 할 수 있는 일 | 참고 |
|---|---|---|
| 매물장 | 등록·수정, 종류·거래·가격·면적·지역 필터, 표/카드 보기, CSV 가져오기 | 금액은 `3억5천`, `12억 3000만`처럼 입력. 면적은 ㎡ 입력 시 평 자동 표시. 같은 주소·지번이면 중복 경고. 소유자·상세주소·내부 메모는 외부 콘텐츠에 쓰이지 않습니다 |
| 고객관리 | 등록·검색, 상담이력, 영업 파이프라인, CSV 가져오기 | 연락처 중복 시 경고. 희망조건을 넣으면 적합 매물이 점수와 사유로 표시됩니다 |
| 물건분석 | 토지·공장창고·상가·아파트 시세·통건물 투자·개발사업 | 자료가 없으면 "자료 없음/확인 필요"로 표시됩니다. 인허가 가능 여부는 단정하지 않습니다. 보고서는 인쇄(PDF 저장)·Excel로 내보냅니다 |
| 업무일지 | 기록, 후속업무 관리, 일간·주간·월간 업무보고 | 보고서는 입력된 기록의 집계입니다 |
| 일정관리 | 월/주/일/목록 보기, 반복 일정, 사전 알림, 충돌 표시 | 알림은 접속할 때 생성됩니다(푸시 없음) |
| 계약관리 | 계약·납부 일정, 상태 관리, 캘린더 등록 | 중개보수·정산은 **대표만** 보입니다 |
| 콘텐츠 스튜디오 | 9개 채널 초안, 사실 검토, 승인·발행 기록, 버전 관리 | 초안 틀의 `【입력 필요】`를 채워야 승인할 수 있습니다. 자동 게시는 없고 "복사 → 직접 게시 → 결과 기록" 방식입니다 |
| 경영 통계 | 월별·지역·종류·가격대·유입경로·담당자별 통계, 콘텐츠 성과 | 조회수는 직접 입력한 값만 집계. 조회수와 계약의 인과관계는 단정하지 않습니다 |
| 설정(대표) | 사용자·역할·비밀번호, 브리핑 기준, 매칭 가중치, 감사 로그 | 직원 퇴사 시 즉시 비활성화 |

## 역할별 권한
| 역할 | 가능한 일 |
|---|---|
| 대표 관리자 | 전체 (중개보수·정산·설정·삭제 포함) |
| 공인중개사 | 매물·고객·계약·업무·일정·분석·콘텐츠(승인 포함) — 중개보수·정산 불가 |
| 중개보조 업무 담당자 | 매물·고객·업무·일정 등록/수정, 분석 열람 — 계약·콘텐츠·통계 불가 |
| 콘텐츠 담당자 | 콘텐츠 작성(승인은 불가), 매물·분석 열람 — 고객·계약 불가 |
| 조회 전용 | 열람만 |

## 콘텐츠 만드는 순서
1. `콘텐츠 스튜디오 → 콘텐츠 만들기` → 매물·채널 선택 → **공개 정보 불러오기**로 글에 쓰일 정보를 먼저 확인합니다(상세주소·소유자·내부 메모는 제외).
2. 가격 공개 여부, 강조할 장점, 제외할 내용을 정하고 **초안 생성**.
3. `【입력 필요】`를 직접 채우고, 상단 **사실 검토** 경고(단정·과장·미확인 호재 표현)를 해결합니다.
4. 상태: 작성중 → 검수중 → **승인**(대표/공인중개사) → 발행예약/발행완료. 승인 후 글을 고치면 다시 검수중으로 돌아갑니다.
5. **원고 복사**로 해당 플랫폼에 직접 게시하고, 발행 URL(또는 "수동 게시 완료")과 조회수·문의 수를 기록합니다.
6. AI 생성은 `ANTHROPIC_API_KEY` 설정 후 사용할 수 있으며, 화면에 표시된 공개 정보가 외부 AI로 전송되는 데 **동의 체크**를 해야 합니다.

## 정산 입력 순서 (대표)
1. `계약관리 → 중개보수 정산`에서 **정산 규칙**(담당자·사무소 비율, 운영비 분담률)을 만듭니다.
2. 계약 상세에서 **약정/실제 수령 중개보수**와 수령일을 기록합니다.
3. **정산 생성** → 지급할 때마다 **지급 기록**. 비율 수정·수령액 변경은 사유가 필수이며 이력이 남습니다.
4. 세금 항목은 입력한 가정률로 계산한 **참고액**입니다. 확정 세액이 아니므로 세무사 확인이 필요합니다.

## 현재 사용할 수 없는 기능
- 기존 매물 사이트(010-8848-7727.com) **자동 연동**: 공식 API/DB 접근이 확인되지 않아 CSV 가져오기만 지원합니다.
- 지도 보기, 사진·문서 업로드, 매물 비교표·고객용 소개자료 출력, 검색조건 저장
- Google Calendar 연동, 푸시·문자 알림
- 블로그·유튜브·인스타 **자동 게시**와 조회수 자동 수집
- 토지이용계획·건축물대장 등 공식 데이터 **자동 조회**(국토부 아파트 실거래가 불러오기는 코드만 있고 실제 호출은 미검증)
- 브리핑 자동 생성 시각 예약 실행(설정값만 저장)
