# 남양주시 주거용 시장 브리핑 대시보드

땅폴레옹 센타부동산(☎ 010-8848-7727)의 고객 상담용 남양주시 주거용 부동산 대시보드입니다.

- **유형 선택:** 아파트 / 빌라(연립·다세대) / 주택(단독·다가구)
- **지역:** 남양주시 읍·면·동별, 주간·월간, 기간 지정
- **지표:** 매매·전세·월세 거래량, 평당가, 전세가율, 신고가, 가격지수
- **TOP10과 지도:** 카카오맵(키가 없으면 OpenStreetMap), 단지 클릭 시 입지분석(교통·학군·상권·개발계획)
- **분양·공급:** 진접2지구·왕숙신도시 분양가와 분양일정(청약홈)
- **기타:** 홈페이지 매물 연결, 브리핑용·홍보용 인쇄

## 실행

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 를 엽니다. Windows에서는 `대시보드_열기.bat` 를 실행해도 됩니다.

## 데이터 업데이트

1. `config.example.json` 을 `config.json` 으로 복사하고 키를 넣습니다.
2. `data/config.example.js` 를 `data/config.js` 로 복사하고 키를 넣습니다.
3. 아래 명령을 실행합니다. Windows에서는 `데이터_업데이트.bat` 를 실행해도 됩니다.

```bash
python fetch_data.py
```

공공데이터포털에서 활용신청이 필요한 서비스:

- 국토교통부 아파트 매매·전월세 실거래가
- 국토교통부 연립다세대 매매·전월세 실거래가
- 국토교통부 단독/다가구 매매·전월세 실거래가
- 한국부동산원 청약홈 분양정보 조회 서비스
